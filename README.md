# bgbc_org

Website source for [Battle Ground Bible Church](https://bgbc.org) (Jekyll + GitHub Pages).

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Open http://127.0.0.1:4000/bgbc_org/

## Notes

- Design notes live in `doc/` (excluded from the published site).
- Sermon audio is intentionally sparse during early migration; see `audio_base_url` in `_config.yml`.
